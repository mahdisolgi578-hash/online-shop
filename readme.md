# بازارینو / فروشگاه اینترنتی\*

**لینک فروشگاه :https://mahdisolgi578-hash.github.io/online-shop/
**
پروژه پایانی کاریار،طراحی یک فروشگاه استاتیک دارای سه صفحه بدون استفاده از کتابخانه و فریم ورک 

## صفحه ها :

\*\* 
index.html:
صفحه فهرست محصولات شامل : سایدبار برای فیلتر ها،نوار جستجو و 6 کارت محصول
product.html:
صفحه جزئیات محصول شامل :گالری تصاویر،قیمت،امتیاز و دیدگاه کاربران
register.html:
فرم ثبت نام با اعتبار سنجی

## ویژگی ها

\*\* 
-جهت متن ها از راست به چپ هست و تمامی متن ها فارسی هستند
-از فونت وزیرمتن استفاده شده است
-flexbox:برای چیدمان صفحه استفاده شده است
-grid:برای چیدمان کارت های محصول استفاده شده است
-media query: برای حالت ریسپانسیو استفاده شده (نقطه شکست 768 و 480 پیکسل)
-prefers-color-scheme : برای حالت تاریک خودکار
-radio:برای ساخت گالری محصول بدون استفاده از جاوا
-sticky:برای ستون فیلتر چسبیده در دسکتاپ
-BEM: برای نامگزاری کلاس ها از این الگو پیروی شده است

## نکته
